# Proof

Raw evidence behind each slice's acceptance: rig reports, logs, menu captures and screenshots, one
folder per slice (`v1-core/`, `v1-menu-today/`, `v1-quit-on-close/`).

Project names in screenshots are redacted (project-a/b) and the backdrop is blanked; numbers unchanged
(OCR-checked before/after). The text captures use the same names, and home paths appear as `~`.
